Weather App:
an interactive weather application built using HTML, Tailwind CSS, and JavaScript.
The app fetches real-time weather data from OpenWeatherMap API, supports location-based weather, recent city suggestions, temperature unit toggle, dynamic backgrounds, and a 5-day forecast.

📁 Project Structure
weather-app/
│
├── index.html        # Main UI structure
├── script.js         # App logic & API handling
├── style.css         # styling of project
└── README.md         # Project documentation

Features

🔍 Search weather by city name
📍 Get weather using current location (Geolocation API)
🌡️ Temperature unit toggle (°C / °F)
🚨 Extreme temperature alerts
🖼️ Dynamic background based on weather condition
📅 5-day weather forecast
🕘 Recent city suggestions (stored in sessionStorage)
❌ Proper error handling for invalid city names.
